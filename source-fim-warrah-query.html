Original text

Unnumbered page · extract

Wanted to know if any one on the Islands has a skin of the native fox and if so if they would sell it and the price? Also if any one can inform the Editor when and where the last wild fox was killed on the East Falklands and the same with regard to the fox on the West Falklands. Also if any person has got or could get the skull of one of them.
